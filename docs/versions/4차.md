# 4차 · 상시 조이스틱·명시적 입력 상태

[프로젝트 소개](../../README.md) · [전체 차수 비교](../VERSIONS.md) · [원본 보관 폴더](../../4%EC%B0%A8/)

**자료 상태: 이전 보관본**

## 🎯 이 자료의 목적

이 문서는 상시 조이스틱·명시적 입력 상태에 관한 안내입니다. 아래 설명은 보관된 소스의 동작과 차이를 정리했으며 새 실행 결과를 뜻하지 않습니다.

## ✨ 구현과 변경 내용

3차와 비교하면 조이스틱 대기 위치를 표시하고 가까운 터치의 원점을 고정하며 손가락 해제 상태를 초기화합니다. 물체는 Transform 중력·낙하 애니메이션을 사용하고 후대 프로필 상점은 아직 없습니다.

근거: [ReferenceGame (1~255행)](../../4%EC%B0%A8/Source/Assets/Scripts/ReferenceGame.cs#L1-L255)

## 🔄 입력·처리·출력

| 단계 | 내용 |
| :--- | :--- |
| 입력 | 터치 입력·레벨 배치·물체와 해당 차수의 에셋 |
| 처리 | 게임 상태 → 이동·충돌·흡수 → 목표·성장 → 화면·저장 |
| 출력 | 게임 화면·레벨/미션 상태·로컬 진행 데이터 |

## 🚀 실행 경로와 제약

초기 HoleItBuilder 계열과 후기 ReferenceBuilder 계열은 만드는 게임 구성이 달라 선택한 차수의 Editor 도구·씬·에셋을 함께 사용해야 합니다. 공개본에는 전체 모델·텍스처·씬·Packages·ProjectSettings가 포함되지 않습니다. 후기 안내의 Unity 6000.3.6f1·Android 모듈 조건을 초기 차수의 확정 버전으로 소급하지 않습니다. Unity·APK 빌드·기기 플레이는 이번 문서 작업에서 실행하지 않았습니다.

1~8차의 실제 보관 폴더를 안내합니다. 8차는 최신보관본이며 별도의 최종 확정 폴더나 출시 완료 상태를 뜻하지 않습니다.

더 자세한 준비 조건·시험 범위·주의점은 [README](../../README.md#quick-start)와 [공개 사본의 처리 범위](../SANITIZATION.md)를 함께 확인해 주세요.
