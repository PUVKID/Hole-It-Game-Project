## LEVEL 1 - Beginner

### LEVEL 1 · 이 자료가 하는 일과 달라진 점

ReferenceCatalog를 바탕으로 모델·배치·목표를 구성하는 Reference 계열의 자료입니다.

### LEVEL 1 · 실제 동작을 따라 읽기

ReferenceCatalog·배치와 묶음 렌더링을 정리했습니다.

ReferenceGame·ReferenceCatalog 기반 모델·배치·목표 구성을 추가합니다. 최대 1,023개 단위 묶음 렌더링과 30레벨 상한을 가지며 조이스틱은 터치 중 표시합니다.

초기 HoleItBuilder 계열과 후기 ReferenceBuilder 계열은 만드는 게임 구성이 달라 선택한 차수의 Editor 도구·씬·에셋을 함께 사용해야 합니다. 공개본에는 전체 모델·텍스처·씬·Packages·ProjectSettings가 포함되지 않습니다. Unity 6000.3.6f1·Android 모듈은 후기 차수의 실행 환경입니다. 초기 차수는 해당 프로젝트 설정에 맞는 환경을 사용합니다.

1~8차에 걸친 게임 구현과 변경 내용을 정리했습니다.

APK는 안드로이드 기기에 설치하는 앱 패키지입니다.

입력 — 터치·조이스틱 입력, 해당 차수 레벨·물체·에셋

처리 — 입력 이동 → 물체 흡수·폭탄 판정 → 미션·성장 → 종료 상태

출력 — 게임 화면·미션/시간 상태·로컬 진행 기록

### LEVEL 1 · 준비하고 확인할 것

해당 차수의 Assets·씬·Packages·ProjectSettings를 같은 버전으로 준비한 Unity 프로젝트가 필요합니다. 공개 소스 보관본은 완전한 씬·모델·텍스처·프로젝트 설정을 모두 포함하지 않습니다. 후기 환경은 Unity 6000.3.6f1과 Android Build Support를 사용합니다.

완전한 같은 차수 Unity 프로젝트에서 씬을 열어 Editor 플레이를 확인하고 대상 플랫폼으로 빌드합니다. C# 파일 복사만으로 APK가 생성되지는 않습니다. 캐시 삭제·원래 사건의 복구 도구는 일반 실행 절차로 사용하지 않습니다.

미션 진행·수집 성장·남은 시간·승패를 구분합니다. 카탈로그와 실제 자산 수를 화면의 고정 홍보 문구로 대신하지 않습니다. 로컬 저장은 서버 동기화나 실제 결제 기록이 아닙니다.

<a name="️-제약과-문제-해결"></a>
## 제약과 문제 해결

**상황:** Unity 프로젝트로 바로 열리지 않음

**확인할 내용:** 해당 차수의 Packages·ProjectSettings·씬과 외부 자산을 준비합니다.

**상황:** 다른 차수 게임이 생성됨

**확인할 내용:** 초기 HoleItBuilder와 후기 ReferenceBuilder의 차수를 확인합니다. 제작 도구는 기존 자산·설정을 덮어쓸 수 있습니다.

**상황:** 모델·충돌체가 누락됨

**확인할 내용:** 선택 차수의 카탈로그·메시·프리팹 조합을 확인합니다.
