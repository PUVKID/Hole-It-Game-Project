## ✨ 구현과 변경 내용

모든 배치 물체의 강체·충돌체를 유지하고 ReferencePhysicsTrigger의 진입·이탈 이벤트를 전달합니다. 활성화 작업은 프레임당 25개씩 진행하며, 전체 강체 수는 이 값으로 제한하지 않습니다.

근거: [ReferenceGame (1~222행)](../../8%EC%B0%A8/Source/Assets/Scripts/ReferenceGame.Physics.cs#L1-L222) · [ReferencePhysicsTrigger (1~10행)](../../8%EC%B0%A8/Source/Assets/Scripts/ReferencePhysicsTrigger.cs#L1-L10)

ReferenceGrowthProgress는 목표·적용 성장 단계를 구분하고 0.3초 뒤 성장시키며 ReferenceGrowthRing은 열린 원형 게이지를 그립니다. 수집 뒤 강체 렌더 유지·승리 후 물리 갱신·전체 bounds 시야 검사가 7차와 다릅니다.

근거: [ReferenceGrowthProgress (1~33행)](../../8%EC%B0%A8/Source/Assets/Scripts/ReferenceGrowthProgress.cs#L1-L33) · [ReferenceGrowthRing (1~42행)](../../8%EC%B0%A8/Source/Assets/Scripts/ReferenceGrowthRing.cs#L1-L42) · [ReferenceGame (1~286행)](../../8%EC%B0%A8/Source/Assets/Scripts/ReferenceGame.cs#L1-L286) · [ReferenceGame (1~118행)](../../8%EC%B0%A8/Source/Assets/Scripts/ReferenceGame.Typography.cs#L1-L118)

## 🚀 실행 경로와 제약

초기 HoleItBuilder 계열과 후기 ReferenceBuilder 계열은 만드는 게임 구성이 달라 선택한 차수의 Editor 도구·씬·에셋을 함께 사용해야 합니다. 공개본에는 전체 모델·텍스처·씬·Packages·ProjectSettings가 포함되지 않습니다. Unity 6000.3.6f1·Android 모듈은 후기 차수의 실행 환경입니다. 초기 차수는 해당 프로젝트 설정에 맞는 환경을 사용합니다. 

1~8차에 걸친 게임 구현과 변경 내용을 정리했습니다.

더 자세한 준비 조건·시험 범위·주의점은 [README](../../README.md#quick-start)와 [공개 사본의 처리 범위](../SANITIZATION.md)를 함께 확인해 주세요.
