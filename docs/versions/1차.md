<a name="features"></a>

<a name="-핵심-기능과-보존-범위"></a>
## 핵심 기능과 보존 범위

| 항목 | 이 차수에서 확인할 내용 |
|---|---|
| 1 | 미션·풀·시간 제한을 갖춘 수집 프로토타입을 정리했습니다. |
| 2 | GameManager·MissionManager·LevelManager·HoleController가 미션 최대 3개, 객체 풀, 타이머·레벨 기록과 Transform 기반 끌기·낙하·반지름 보간을 연결합니다. |
| 3 | 미션·객체 풀·시간 제한을 연결한 수집 게임의 기본 흐름을 구현했습니다. |
| 4 | 초기 HoleItBuilder 계열과 후기 ReferenceBuilder 계열은 만드는 게임 구성이 달라 선택한 차수의 Editor 도구·씬·에셋을 함께 사용해야 합니다. 공개본에는 전체 모델·텍스처·씬·Packages·ProjectSettings가 포함되지 않습니다. Unity 6000.3.6f1·Android 모듈은 후기 차수의 실행 환경입니다. 초기 차수는 해당 프로젝트 설정에 맞는 환경을 사용합니다. |

<a name="-입력처리출력"></a>
## 입력·처리·출력

| 단계 | 내용 |
|---|---|
| 입력 | 터치·조이스틱 입력, 해당 차수 레벨·물체·에셋 |
| 처리 | 입력 이동 → 물체 흡수·폭탄 판정 → 미션·성장 → 종료 상태 |
| 출력 | 게임 화면·미션/시간 상태·로컬 진행 기록 |

<a name="usage"></a>

<a name="️-화면과-사용-흐름"></a>
## 화면과 사용 흐름

1. 해당 차수의 레벨·미션·물체 데이터를 Unity 편집기에서 연결합니다.
2. 플레이 모드에서 터치·드래그로 홀을 이동합니다.
3. 흡수한 물체와 미션 수·시간 제한·성장 상태를 확인합니다.
4. 승패와 다음 레벨 저장을 확인하며 다른 차수의 Builder를 섞지 않습니다.

<a name="-설치-환경과-실행사용법"></a>
## 설치 환경과 실행·사용법

해당 차수의 Assets·씬·Packages·ProjectSettings를 같은 버전으로 준비한 Unity 프로젝트가 필요합니다. 공개 소스 보관본은 완전한 씬·모델·텍스처·프로젝트 설정을 모두 포함하지 않습니다. 후기 환경은 Unity 6000.3.6f1과 Android Build Support를 사용합니다.

완전한 같은 차수 Unity 프로젝트에서 씬을 열어 Editor 플레이를 확인하고 대상 플랫폼으로 빌드합니다. C# 파일 복사만으로 APK가 생성되지는 않습니다. 캐시 삭제·원래 사건의 복구 도구는 일반 실행 절차로 사용하지 않습니다.

<a name="results"></a>

<a name="-처리-결과와-출력-읽기"></a>
## 처리 결과와 출력 읽기

미션 진행·수집 성장·남은 시간·승패를 구분합니다. 카탈로그와 실제 자산 수를 화면의 고정 홍보 문구로 대신하지 않습니다. 로컬 저장은 서버 동기화나 실제 결제 기록이 아닙니다.

<a name="️-제약과-문제-해결"></a>
## 제약과 문제 해결

| 상황 | 확인할 내용 |
|---|---|
| Unity 프로젝트로 바로 열리지 않음 | 해당 차수의 Packages·ProjectSettings·씬과 외부 자산을 준비합니다. |
| 다른 차수 게임이 생성됨 | 초기 HoleItBuilder와 후기 ReferenceBuilder의 차수를 확인합니다. 제작 도구는 기존 자산·설정을 덮어쓸 수 있습니다. |
| 모델·충돌체가 누락됨 | 선택 차수의 카탈로그·메시·프리팹 조합을 확인합니다. |
