## ✨ 구현과 변경 내용

TMP와 Typography·스타일, 챌린지·3D 도감·31일 출석을 연결합니다. ReferenceAttendance는 로컬 날짜의 중복 수령을 막고 코인 보상을 적용합니다.

근거: [ReferenceGame (1~41행)](../../6%EC%B0%A8/Source/Assets/Scripts/ReferenceGame.Typography.cs#L1-L41) · [ReferenceAttendance (1~27행)](../../6%EC%B0%A8/Source/Assets/Scripts/ReferenceAttendance.cs#L1-L27) · [ReferenceProfile (1~25행)](../../6%EC%B0%A8/Source/Assets/Scripts/ReferenceProfile.cs#L1-L25)

배치 장애물·랜덤 폭탄과 게임 상태를 확장합니다. 화면의 465레벨·1,010물체 표시는 고정 문구이며 실제 레벨·물체 구성은 연결된 카탈로그와 에셋에 따릅니다.

근거: [ReferenceGame (1~162행)](../../6%EC%B0%A8/Source/Assets/Scripts/ReferenceGame.Levels.cs#L1-L162) · [ReferenceGame (1~62행)](../../6%EC%B0%A8/Source/Assets/Scripts/ReferenceGame.Presentation.cs#L1-L62)

## 🚀 실행 경로와 제약

초기 HoleItBuilder 계열과 후기 ReferenceBuilder 계열은 만드는 게임 구성이 달라 선택한 차수의 Editor 도구·씬·에셋을 함께 사용해야 합니다. 공개본에는 전체 모델·텍스처·씬·Packages·ProjectSettings가 포함되지 않습니다. Unity 6000.3.6f1·Android 모듈은 후기 차수의 실행 환경입니다. 초기 차수는 해당 프로젝트 설정에 맞는 환경을 사용합니다. 

1~8차에 걸친 게임 구현과 변경 내용을 정리했습니다.

더 자세한 준비 조건·시험 범위·주의점은 [README](../../README.md#quick-start)와 [공개 사본의 처리 범위](../SANITIZATION.md)를 함께 확인해 주세요.
