## 🎯 개발 내용

별도 PhysX 장면·강체 풀과 로컬 상점을 정리했습니다.

## ✨ 구현과 변경 내용

ReferenceGame을 부분 클래스로 나누고 LocalPhysics3D 장면·강체 풀 384개와 비동기 로딩을 구성합니다. Transform 낙하 위주의 4차와 물리 경로가 달라집니다.

근거: [ReferenceGame (1~258행)](../../5%EC%B0%A8/Source/Assets/Scripts/ReferenceGame.cs#L1-L258) · [ReferenceGame (1~150행)](../../5%EC%B0%A8/Source/Assets/Scripts/ReferenceGame.Physics.cs#L1-L150) · [ReferenceGame (1~60행)](../../5%EC%B0%A8/Source/Assets/Scripts/ReferenceGame.Presentation.cs#L1-L60)

ReferenceProfile은 코인·하트·부스터·상점과 로컬 저장을 담당합니다. 카탈로그 레벨 수를 사용하며 이전 30레벨 상한과 구분합니다.

근거: [ReferenceProfile (1~17행)](../../5%EC%B0%A8/Source/Assets/Scripts/ReferenceProfile.cs#L1-L17) · [ReferenceGame (1~43행)](../../5%EC%B0%A8/Source/Assets/Scripts/ReferenceGame.Profile.cs#L1-L43)

## 🔄 입력·처리·출력

| 단계 | 내용 |

| 처리 | 게임 상태 → 이동·충돌·흡수 → 목표·성장 → 화면·저장 |
| 출력 | 게임 화면·레벨/미션 상태·로컬 진행 데이터 |

## 🚀 실행 경로와 제약

초기 HoleItBuilder 계열과 후기 ReferenceBuilder 계열은 만드는 게임 구성이 달라 선택한 차수의 Editor 도구·씬·에셋을 함께 사용해야 합니다. 공개본에는 전체 모델·텍스처·씬·Packages·ProjectSettings가 포함되지 않습니다. Unity 6000.3.6f1·Android 모듈은 후기 차수의 실행 환경입니다. 초기 차수는 해당 프로젝트 설정에 맞는 환경을 사용합니다. 

1~8차에 걸친 게임 구현과 변경 내용을 정리했습니다.

더 자세한 준비 조건·시험 범위·주의점은 [README](../../README.md#quick-start)와 [공개 사본의 처리 범위](../SANITIZATION.md)를 함께 확인해 주세요.
