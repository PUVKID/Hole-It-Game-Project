# 9차 · 제품 스크립트 8개 부분 보관

[보관 폴더](../../9차/제품소스/) · [8차와 대응 가능한 파일 전체 비교](../revision-audit/9차.md)

원본 9차는 outputs·work 폴더를 가진 작업 자료입니다. 확인한 제품 스크립트 8개만 공개 사본에 보존되어 있습니다. 완전한 Unity 프로젝트·새 APK 완성본·8차 Reference 계열 이후의 정식 기능 확장으로 설명하지 않습니다.

게임 상태·레벨 관리·검사, 물체, 가족 모드·미션 행·미리보기 코드를 포함합니다. `GameManager`는 `GameState`와 미션·타이머·성장·폭탄을 연결하는 코드입니다. `ReferenceGame` 중심의 8차 게임과 동일 구현이라고 단정할 수 없습니다. 소스의 존재와 유효한 플레이 결과는 서로 다른 근거입니다.

비교에서 8차에만 있는 파일은 9차 원본에서 기능이 삭제되었다는 뜻이 아닙니다. 파일을 추가 생성하거나 누락 씬·모델·설정을 추정해 채우지 않았습니다. 코드 열람과 원본 대응 확인 범위이며 Unity 컴파일·APK 설치·실기기 시험은 실행하지 않았습니다.
