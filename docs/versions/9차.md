## LEVEL 1 - Beginner

### LEVEL 1 · 이 자료가 하는 일과 달라진 점

게임 상태·점수·미션·보상·가족 모드·미리보기를 읽는 제품 스크립트 부분본입니다. 의존성을 모두 연결한 Unity 프로젝트는 포함하지 않습니다.

### LEVEL 1 · 실제 동작을 따라 읽기

GameManager가 상태 전이·점수·시간·미션 완료를 조율하는 제품 스크립트 부분본입니다.

필수 씬 참조·ObjectPooler·성장표가 없거나 유효하지 않으면 오류를 남기고 컴포넌트를 비활성화합니다.

SessionId와 TryClaimReward로 이전 세션의 풀링 객체가 보상을 다시 지급하는 경로를 차단합니다.

가족 모드 또는 timeLimit=0은 무제한 시간으로 처리하고, 일시정지와 앱 포커스 상실 시 입력을 멈춥니다.



입력 — GameManager 등 보존된 C# 8개와 직렬화된 외부 참조 선언

처리 — 초기화 검사·상태 전이·보상 소유권·미션·일시정지 코드 읽기

출력 — 게임 상태와 보상 처리의 구현 설명

### LEVEL 1 · 준비하고 확인할 것

UTF-8 소스 편집기로 읽습니다. GameSettings·씬 참조·성장표·풀링 객체 등 코드가 요구하는 요소를 별도로 식별합니다. 이 폴더에는 그 의존성을 모두 연결한 Unity 프로젝트가 없습니다.

관련 파일을 아래 링크에서 열어 순서대로 대조합니다.

#### LEVEL 1 · GameManager의 상태·시간·보상 경계

`Start`는 목표 프레임60, vSyncCount=0과 화면 꺼짐 방지를 설정한 뒤 필수 참조를 검사합니다. 정상 초기화 이후 UI·미션·성장 이벤트를 구독하고 풀링 효과를 미리 준비합니다. `BeginLoading`은 세션 ID를 증가시키며 이전 입력과 이동 소리를 멈춥니다. 레벨 로딩 실패는 Failed와 `LEVEL DATA ERROR` 표시로 이어집니다.

`StartLevel`은 범위를 벗어나거나 잠금 상태인 레벨을 거부하고 점수·미션 보너스를0으로 초기화합니다. Ready 대기는 최소0.1초이며 준비 종료 뒤에만 입력을 켭니다. 시간은 Playing에서만 줄고0이 되면 `TIME UP`으로 실패합니다. 제한시간0 또는 `FamilyMode.Relaxed`이면 무제한으로 처리합니다.

`OnEdibleConsumed`는 Playing·객체 존재·`TryClaimReward(SessionId)`를 통과해야 점수와 성장을 반영합니다. 잘못된 목표는 설정에 따라 점수/시간 페널티 또는 예약 차단을 적용합니다. 시간 보너스는 최대3,600초로 제한하고 미션 등록 뒤 상태가 바뀔 수 있으므로 그 뒤 추가 보상을 하지 않습니다.

모든 미션 완료는 Clearing으로 이동하고0.3~0.8초 뒤 종료 보상을 계산합니다. 재시도는 Failed·LevelClear·Paused에서만 가능합니다. Pause는 시간 배율0과 입력 중단, Resume는 배율1과 Playing 복귀입니다. 파괴 시 이벤트 구독을 해제하고 배율1로 복원합니다.

1. GameManager.Start의 필수 참조 검사와 enabled=false 종료를 읽습니다.
2. BeginLoading이 SessionId를 증가시키고 입력·이동을 잠그는 순서를 확인합니다.
3. Ready→Playing→Clearing→LevelClear와 시간 초과 Failed 경로를 대조합니다.
4. Pause/Resume 및 OnDestroy의 이벤트 해제·시간 배율 복원을 확인합니다.

### LEVEL 1 · 결과와 주의할 범위

GameManager의 상태·점수·타이머 계산과 재시도·일시정지·종료 분기를 읽을 수 있습니다.

**상황:** 필수 클래스·씬이 없음

**확인할 내용:** 보존한 8개 파일의 외부 참조를 확인합니다. 다른 차수의 에셋을 동일 버전으로 가정하지 않습니다.

**상황:** 보상 중복 처리 검토

**확인할 내용:** Playing 상태와 TryClaimReward(SessionId) 검사를 함께 읽습니다.

**상황:** 중단 뒤 상태 검토

**확인할 내용:** OnApplicationPause/Focus는 Pause를 호출하며 OnDestroy는 Time.timeScale을 1로 복원합니다.


### LEVEL 1 · 도구 옵션과 결과 해석

실제 제품 코드는 시작 때 목표 프레임60·vSyncCount=0·화면 꺼짐 방지를 설정하고 필수 참조가 유효한지 검사합니다. 잠겼거나 범위를 벗어난 레벨은 시작하지 않고 점수·미션 보너스를0으로 되돌립니다. 준비는 최소0.1초이며 준비가 끝나야 입력을 켭니다. 시간은 Playing에서만 줄고0이면 TIME UP으로 실패하지만 timeLimit=0·가족 Relaxed모드는 무제한입니다. **미션 완료와 보상 계산은 즉시 같은 일이 아닙니다.** Clearing 뒤0.3~0.8초에 종료 보상을 계산하며 시간 보너스는 최대3,600초입니다. 잘못된 목표는 설정에 따른 점수/시간 벌점이나 예약 차단이 있고 미션 등록 뒤 종료 상태가 되면 추가 보상을 하지 않습니다. 재시도는 Failed·LevelClear·Paused에서만 가능하며 파괴될 때 이벤트 연결을 풀고 시간 배율1로 복원합니다.

`OnEdibleConsumed`는 Playing·객체 존재·`TryClaimReward(SessionId)`를 통과해야 점수와 성장을 반영합니다. 잘못된 목표는 설정에 따라 점수/시간 페널티 또는 예약 차단을 적용합니다. 시간 보너스는 최대3,600초로 제한하고 미션 등록 뒤 상태가 바뀔 수 있으므로 그 뒤 추가 보상을 하지 않습니다.

모든 미션 완료는 Clearing으로 이동하고0.3~0.8초 뒤 종료 보상을 계산합니다. 재시도는 Failed·LevelClear·Paused에서만 가능합니다. Pause는 시간 배율0과 입력 중단, Resume는 배율1과 Playing 복귀입니다. 파괴 시 이벤트 구독을 해제하고 배율1로 복원합니다.

<a name="️-제약과-문제-해결"></a>
## 제약과 문제 해결

**상황:** 필수 클래스·씬이 없음

**확인할 내용:** 보존한 8개 파일의 외부 참조를 확인합니다. 다른 차수의 에셋을 동일 버전으로 가정하지 않습니다.

**상황:** 보상 중복 처리 검토

**확인할 내용:** Playing 상태와 TryClaimReward(SessionId) 검사를 함께 읽습니다.

**상황:** 중단 뒤 상태 검토

**확인할 내용:** OnApplicationPause/Focus는 Pause를 호출하며 OnDestroy는 Time.timeScale을 1로 복원합니다.
