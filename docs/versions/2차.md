## ✨ 구현과 변경 내용

EdibleData.stackHeight·LevelData 배치 높이와 EnableStackPhysics로 쌓인 물체를 처리합니다. HoleController는 월드 좌표 DragTarget 추적과 경계 제한을 적용합니다.

근거: [EdibleData (1~40행)](../../2%EC%B0%A8/Source/Assets/Scripts/Data/EdibleData.cs#L1-L40) · [LevelData (1~81행)](../../2%EC%B0%A8/Source/Assets/Scripts/Data/LevelData.cs#L1-L81) · [LevelManager (1~45행)](../../2%EC%B0%A8/Source/Assets/Scripts/Core/LevelManager.cs#L1-L45) · [HoleController (1~139행)](../../2%EC%B0%A8/Source/Assets/Scripts/Hole/HoleController.cs#L1-L139)

폭탄은 미션 수집에서 제외하며 소비 실패·폭탄 처리 중 승리 유예를 다룹니다. 이름이 Korean.Text인 함수는 일부 한국어를 영문으로 돌리는 마이그레이션이므로 한국어 현지화 추가로 설명하지 않습니다.

근거: [GameManager (1~115행)](../../2%EC%B0%A8/Source/Assets/Scripts/Core/GameManager.cs#L1-L115) · [Korean (1~41행)](../../2%EC%B0%A8/Source/Assets/Scripts/UI/Korean.cs#L1-L41)

## 🚀 실행 경로와 제약

초기 HoleItBuilder 계열과 후기 ReferenceBuilder 계열은 만드는 게임 구성이 달라 선택한 차수의 Editor 도구·씬·에셋을 함께 사용해야 합니다. 공개본에는 전체 모델·텍스처·씬·Packages·ProjectSettings가 포함되지 않습니다. Unity 6000.3.6f1·Android 모듈은 후기 차수의 실행 환경입니다. 초기 차수는 해당 프로젝트 설정에 맞는 환경을 사용합니다. 

1~8차에 걸친 게임 구현과 변경 내용을 정리했습니다.

더 자세한 준비 조건·시험 범위·주의점은 [README](../../README.md#quick-start)와 [공개 사본의 처리 범위](../SANITIZATION.md)를 함께 확인해 주세요.
