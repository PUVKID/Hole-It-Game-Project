# 2차·공개 파일 전체 비교

비교 기준: **1차**. 비교 경로는 [2차\Source](../../../2%EC%B0%A8/Source)입니다.

공개 파일 2144개. 추가 1400·수정 225·이전에만 존재 37·동일 519개입니다. 파일 수·텍스트 차이가 동작·성능 개선을 자동으로 입증하지 않습니다.

이전만 존재는 이번 보관 범위에 없는 파일이며 원본 기능 삭제로 단정하지 않습니다. 비교 경로 내 모든 공개 파일을 집계합니다.

- [공백·주석을 포함한 공개 텍스트 전체 차이](../../revision-audit/2%EC%B0%A8.patch)

저작권·라이선스, 이메일, 제품 호환 식별자와 필수 저장소 링크는 유지합니다.

원래 비공개 값이 삭제 줄에 다시 나타나지 않도록 양쪽 입력을 먼저 정리했으며 원본의 무 가공 바이 트 패치와 구분합니다.

BOM의 표시 차이와 인코딩 변환은 바이트 해시·별도 원 문 해 시 기록으로 구분하며 JSON해 시는 실제 공개 사 본의 바이트 기준입니다.

공백·주석을 무시하는 옵션은 사용하지 않았고, 바이너리 내용은 추정하지 않았습니다.

이 전 소스·빌드 실행·실 기기 검증을 이번에 재수행한 결과가 아닙니다.
