# 9차·공개 파일 전체 비교

비교 기준: **8차**. 비교 경로는 [9차\제품소스](../../../9%EC%B0%A8/%EC%A0%9C%ED%92%88%EC%86%8C%EC%8A%A4)입니다.

9차는 원본 작업 폴더에서 확인한 8개 제품 스크립트의 부분 보존 본입니다. 전체 9차 Unity 프로젝트·8차의 후속 기능 완성 본이 아닙니다. 이전만 존재하는 파일은 이 부분 보관본에 없는 것이며 원본에서 삭제된 기능으로 단정하지 않습니다. Scripts 경로는 비교용으로 Assets/Scripts에 대응시켰습니다.

공개 파일 8개. 추가 0·수정 8·이전에만 존재 2358·동일 0개입니다. 파일 수·텍스트 차이가 동작·성능 개선을 자동으로 입증하지 않습니다.

이전만 존재는 이번 보관 범위에 없는 파일이며 원본 기능 삭제로 단정하지 않습니다. 비교 경로 내 모든 공개 파일을 집계합니다.

- [공백·주석을 포함한 공개 텍스트 전체 차이](../../revision-audit/9%EC%B0%A8.patch)
- [전체 파일별 크기·SHA-256](../../revision-audit/9%EC%B0%A8.files.json)

개인 표시와 로컬 사용자 경로를 정리한 각 공개 사 본의 실제 바이트를 비교했습니다.

저작권·라이선스, 이메일, 제품 호환 식별자와 필수 저장소 링크는 유지합니다.

원래 비공개 값이 삭제 줄에 다시 나타나지 않도록 양쪽 입력을 먼저 정리했으며 원본의 무 가공 바이 트 패치와 구분합니다.

BOM의 표시 차이와 인코딩 변환은 바이트 해시·별도 원 문 해시 기록으로 구분하며 JSON해시는 실제 공개 사 본의 바이트 기준입니다.

공백·주석을 무시하는 옵션은 사용하지 않았고, 바이너리 내용은 추정하지 않았습니다.
