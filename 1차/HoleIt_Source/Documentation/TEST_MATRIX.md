# 검증 상태표

상태 정의: **PASS**는 명시된 범위의 도구를 실제 실행해 통과, **FAIL**은 실제 검사 실패, **NOT RUN**은 미실행, **BLOCKED**는 실행 환경 부족입니다. 오프라인 검사의 PASS를 Unity 검사 PASS로 확장하지 않습니다.

**검사:** 프로젝트 루트·필수 파일·버전

**결과:** PASS

**근거 / 경계:** 실제 디렉터리/파일/버전 문자열 확인

**검사:** 메타 GUID

**결과:** PASS

**근거 / 경계:** 374개 고유 GUID, 필수 파일/폴더 메타 존재

**검사:** Unity 텍스트 YAML 파싱

**결과:** PASS

**근거 / 경계:** 220파일, 2,410개 직렬화 객체. Unity 임포트 아님
