# 에셋 출처 및 원본 보존

## 사용자 제공 원본

입력 파일은 `HoleIt_Full_Project_ModelRefresh_v7_fixed.zip`입니다. 원본 50개 파일의 SHA-256 목록은 `OriginalInventory.json`, 입력 ZIP 원본은 `OriginalSourceSnapshot.zip`에 있습니다. 기존 클래스/Editor 모델 빌더/셰이더를 읽고 수정·재사용했으며 원본 파일을 다른 프로젝트인 것처럼 대체하지 않았습니다.

## 이번 작업에서 생성한 자료

51종 수집 모델의 메시, 정점 색상, 프리팹, 데이터와 51개 아이콘은 코드로 생성했습니다. 도넛 링, 차량 차체/바퀴/유리, 버스, 음식/장난감/도시 소품 등은 유형별 형태 조합입니다. 4개 UI 이미지와 17개 WAV(효과/이동 11개, 테마 6개)도 절차 생성했습니다. 6개 테마, 30개 레벨 및 957개 배치는 자체 작성한 데이터입니다.

작업에 사용한 생성 코드의 이식본은 `Tools/OfflineAuthoring`에 포함했습니다. 메시 생성에는 기존 사용자 모델 키트도 계속 보존되어 있습니다. 신규 VertexLit 셰이더와 기존 Built-in 홀 셰이더를 사용합니다.

게임 내 타이틀은 텍스트 기반 `POCKET PIT`입니다. 원작 게임의 코드, 모델, 텍스처, 음원, 로고, 레벨 파일을 새로 다운로드하거나 추출하지 않았습니다. 사용자 원본에 포함된 내용의 권리 관계 자체를 조사한 것은 아닙니다.

## 폰트 및 프리뷰

외부 폰트 파일은 제출하지 않습니다. UI 코드가 사용하는 `LegacyRuntime.ttf`는 Unity 내장 리소스 경로이며 ZIP에 폰트 파일로 담지 않았습니다. `Asset_Contact_Sheet.png`는 51개 생성 아이콘을 한 화면에 놓은 **오프라인 확인용 이미지**로, Unity에서 촬영한 게임 화면이 아닙니다.

독자적인 자료 생성과 제3자 권리/상표 검토는 별개의 작업입니다. 배포 전 프로젝트명·패키지명·기존 원본의 사용 권한 확인은 별도 남아 있으며 이 문서는 법적 검토 완료를 뜻하지 않습니다.
