# 알려진 제한사항 및 검증 대기 항목

## 실행 환경 때문에 확인하지 못한 사항

- Unity Editor가 없어 최초 임포트, 전체 C# 의미 분석/컴파일, 셰이더 컴파일, 씬 로드, Prefab 연결 상태의 Editor 확인을 하지 못했습니다. dotnet/mcs/csc도 없습니다. 오프라인 어휘/중괄호 검사는 컴파일의 대체물이 아닙니다.
- 실제 Main 플레이, 모바일 터치, 화면비/노치 렌더링, 전경·백그라운드 복귀, 효과음 청취, 실기기 성능/GC/프레임률, 장시간 실행 및 앱 재설치/저장 복원 테스트는 미실행입니다.
- Unity Test Runner의 EditMode/PlayMode 테스트는 작성했지만 실행하지 않았습니다. 검사 코드는 Unity에서 추가 조정이 필요할 수 있습니다.
- Android 모듈, SDK/NDK/JDK, 라이선스 및 IL2CPP 빌드 체인이 확인되지 않아 APK가 없습니다. 스토어 제출 심사/정책 확인이나 서명·업로드도 하지 않았습니다.

## 데이터·파일 검사의 범위

Main, Mesh, Prefab, ScriptableObject의 실제 텍스트 파일을 작성하고 파싱·GUID/fileID·연결 관계를 검사했습니다. **Unity가 이 직렬화 파일을 성공적으로 임포트했다고 확인한 것은 아닙니다.** 최초 Unity 임포트에서 파일 형식 또는 API 문제를 발견할 수 있습니다.

패키지 잠금 파일은 의존성을 맞춰 작성한 **초기 seed lock**입니다. 실제 Unity Package Manager가 내려받아 생성한 파일이 아닙니다. 패키지 해결 후 Editor가 갱신할 수 있으며 그 결과를 별도로 확인해야 합니다. Input System 1.14.0은 기존 버전을 유지했습니다.

30개 레벨에는 실제 배치와 목표를 저장했고 수량, 경계, 겹침, 시작 여유, 논리적 도달 반경, Tier 성장 경로를 검사했습니다. 검증기의 낮은 Tier 우선 경로는 **완료 가능성을 위한 데이터 순서 검증이지 제한시간 내 자동 플레이나 최적 경로 증명은 아닙니다.** 특히 후반 Penalty 레벨은 불필요한 성장용 물체를 모두 먹으면 시간이 부족할 수 있어 목표 우선 경로와 실제 시간 밸런스를 플레이로 조정해야 합니다.

Safe Area 검사는 5가지 크기의 수식 결과 확인입니다. 실제 Unity 렌더 결과나 모든 휴대전화/태블릿의 가독성을 보증하지 않습니다. `Asset_Contact_Sheet.png`는 생성 아이콘 검수용 모음이며 Unity 플레이 화면이 아닙니다.

## 구현 및 복구 범위

게임 문구는 영어이며 한국어 게임 UI/다국어 전환은 없습니다. 문서만 한국어입니다. 실제 외부 폰트 파일은 포함하지 않으며 Unity 내장 폰트 경로를 사용하는 코드로 작성했습니다.

미션 UI 및 예약 저장소는 최대 3개 동시 미션을 기준으로 합니다. 현재 30레벨은 이 범위 안에 있습니다. 기본 캠페인에는 모든 제공 모델이 사용되지는 않으며 최대 성장 Tier 전체가 모든 레벨에서 필요한 것도 아닙니다.

흡수·성장·완료 효과는 재사용 링/메시 입자 및 움직임 연출입니다. 제출 native FX 프리팹에서 ParticleSystem 참조가 비어 있어도 해당 메시 효과를 사용하도록 작성했습니다. 별도 고급 소용돌이 셰이더, 햅틱 조정, 광고/결제, 분석 SDK, 클라우드 저장, 온라인 순위표는 구현하지 않았습니다.

기존 C# Builder는 제출 에셋을 보존·재사용하고 Main 누락 시 재구성을 지원하는 경로입니다. 모든 ThemeData와 UI 프리팹까지 삭제한 상태의 완전 복구는 원형 ZIP/보호된 오프라인 생성 도구가 필요합니다. 오프라인 도구 이식본의 전체 재생성은 재실행하지 않았고 구문 및 무단 실행 차단만 확인했습니다.

기존 전역 최고점은 레벨 정보가 없어 레벨별 TOP 3로 임의 이관하지 않았습니다. 원래 키는 보존합니다. 레벨 진행 중 중간 상태를 저장해 그 자리에서 이어 하는 기능은 없습니다.

## Unity에서 우선 확인할 순서

1. 6000.3.6f1로 패키지 해결과 최초 임포트/컴파일을 완료하고 Console 오류를 해결합니다.
2. Main 씬 및 홀의 마스크·바닥·깊이·림 렌더 순서를 확인합니다.
3. 프로젝트 검사, EditMode, PlayMode 테스트를 실제 실행합니다.
4. 1·3·10·17·20·27·30레벨의 조작/시간/부스터/벌칙/성장/Blocked 완료를 우선 확인하고 이후 30레벨을 모두 완주합니다.
5. Android 개발 빌드에서 터치, 화면비, 재시작/홈/중단 복귀, 저장 및 성능을 측정합니다.

이 목록을 완료하기 전에는 출시 검증이 끝난 게임으로 취급하지 않습니다.
