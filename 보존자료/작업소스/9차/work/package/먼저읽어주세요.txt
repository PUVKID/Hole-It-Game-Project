포켓 홀 — 가은이의 쏙쏙 수집 놀이
2026-10-13 / 매끈한 모형 · 화장품 탑 에디션 / 개인 설치용 Android 버전

설치
1. ZIP 압축을 해제합니다.
2. PocketPit_Gaeun.apk 파일을 안드로이드 휴대전화에 복사합니다.
3. 휴대전화에서 파일을 열고, 요청되는 경우 해당 파일 앱의 '이 출처 허용'을 켜서 설치합니다.
4. 앱 목록에서 '포켓 홀'을 실행합니다.
Android 8.0 이상, ARM64 또는 ARMv7 기기용입니다. 아이폰에서는 설치할 수 없습니다.
이 APK는 개인 설치용 테스트 서명을 사용합니다. 스토어 등록용 배포 서명은 아닙니다.

게임 방법
- 시작하기를 누르고, 화면을 누른 채 원하는 방향으로 손가락을 끌어 주세요.
- 작은 물건을 삼키면 구멍이 커지고 더 큰 물건을 삼킬 수 있습니다.
- 화면 위에 표시된 물건과 개수를 모두 채우면 다음 스테이지가 열립니다.
- 일부 스테이지는 다른 물건을 먹으면 감점되거나, 목표 물건만 먹을 수 있습니다.
- 처음 화면의 '도전 모드' 버튼을 누르면 시간 제한 없는 '여유 모드'로 바뀝니다.
- 설정에서 조이스틱 방식, 전체 음량, 배경 음악, 효과음을 바꿀 수 있습니다.
- 일시정지, 재시작, 스테이지 선택과 최고 기록 저장을 지원합니다.
- 인터넷, 광고, 인앱 결제 없이 동작합니다.

포함 내용
- PocketPit_Gaeun.apk: 설치 파일
- Source: 편집·재빌드 가능한 Unity 프로젝트 전체
- 미리보기: 이 프로젝트를 렌더링한 실제 게임 화면
- 검증결과: 자동 검사 결과 및 확인 범위
- SHA256.txt: 파일 무결성 확인용 해시

원작과의 관계
사용자가 제공한 HoleIt_Source_Fixed.zip 프로젝트를 개선했습니다.
Hole it!의 블랙홀 이동·수집·성장·목표 달성 방식을 참고한 별도 게임입니다.
원작의 소스, 그래픽, 맵, 이름을 그대로 복제한 제품이 아니며,
원작과 동일한 그래픽·물리·콘텐츠 양·상용 완성도를 보장하지 않습니다.
이 버전에는 기존 프로젝트 기반의 30개 스테이지, 63종 모형, 한국어 UI, 여유 모드,
나눔고딕 Bold 내장, 독자 아이콘과 수정된 화면·조명이 들어 있습니다.
립스틱, 향수, 매니큐어, 크림, 팩트, 로션, 비누, 브러시, 세럼과
마카롱, 주스, 초콜릿을 추가했습니다. 탑은 실제 Rigidbody 중력을 사용합니다.

검증 범위
정확한 최종 통과 수와 APK 검사 결과는 검증결과/검증요약.txt에 있습니다.
자동 플레이는 여유 모드에서 실제 이동·충돌·흡수를 통과하도록 검사합니다.
모든 시간제한 스테이지의 난이도나 사람의 플레이 경험을 보증하는 검사는 아닙니다.
연결된 Android 실기기가 없어 설치 후 터치, 발열, 배터리, 기기별 FPS는 미확인입니다.

소스 열기
Unity Hub에서 Source 폴더를 추가합니다.
Unity 6000.3.6f1 및 Android Build Support(SDK, NDK, OpenJDK)가 필요합니다.
Assets/Scenes/Main.unity를 열어 Play를 누릅니다.
빌드는 Source/Build-Android.ps1 또는 HoleIt > 2. Android APK 빌드 메뉴를 사용합니다.
최종 Main 씬은 이미 저장되어 있으므로 전체 프로젝트 재생성은 필요하지 않습니다.
Library 등 임시 캐시는 제외했습니다. 처음 열 때 패키지 다운로드/임포트가 필요합니다.
