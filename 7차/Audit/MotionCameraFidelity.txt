Edition 7 movement / growth / camera evidence
Source: user-supplied Hole+it! 1.31.17; extracted Unity assets and ARM32 libil2cpp.so.
Native addresses below are RVAs, also file offsets in this supplied ELF.

Movement
- level2 GameInputManager path ID 2409: moveSpeed 2.6, SpeedIncreaseRate .442,
  arrowRotationSpeed 40. Start (0x1977ADC) stores 2.6 as the base speed.
- SetNewSpeed (0x19722C8): base + .442 * actual physical growth tier.
- Update (0x19782BC) passes direction * speed to CharacterController.SimpleMove;
  no additional velocity lerp. Manual position integration requires dt exactly once.
  The source call resolves through 0x26D91A4 to SimpleMove at 0x53048D8.
- Speed booster multiplier 1.3. Ordinary growth updates speed at the .3-second
  expansion callback, except when the physical-cap flag is set. Normal tier 9 speed
  is 6.578; reaching tier 10 skips the callback. A later booster transition computes
  tier 10's full 7.02 baseline (9.126 boosted).
- level2 VariableJoystick path ID 2913: HandleRange 1, DeadZone 0, Floating mode 1.
  Retain the zero-magnitude guard when accepting a zero dead zone.

- HoleScaleUpWithAnimation (0x197117C) target is (newSize * 1.125, newSize, newSize),

- SetNextSizeLevel (0x1970ED4) reaches actual tier 10 then returns before the normal

Limits of this evidence
- These are exact extracted settings and the inspected native operations. The
  recreation uses its own renderer and collision architecture, so these changes
  do not by themselves prove pixel-identical framing or identical Unity physics.
- Camera debug preferences in an existing original installation could override
  defaults. The recreation implements the verified clean-launch Height mode.
- The camera helper preserves observed cap behavior deliberately, including the
  unusual skipped normal camera/speed callback at actual tier 10.

Integration review after parent changes
- Main Update now uses Time.deltaTime, velocity directly and immediate contact radius.
- Radius uses environment contact base + .223*tier + .30 while size boosted.
- Visual scaling composes X/normalScale on the root and the uniform graphics scale,
  reproducing the helper's X-width pulse while retaining the target Y/Z scale.
- Growth speed callback runs on the .3 expansion crossing, with actual cap state set
  first. Camera event runs separately from the size animation as in the source.
- LateUpdate uses camera state and source damping, without the old .05 dt cap.
- RenderActors derives its distance from actual camera offset; camera growth therefore
  expands the culling range as well as the view.
- Existing real-touch .4-second movement guard (> .5 units and < speed*.55) remains
  meaningful at speed 2.6 (expected about 1.04 units) and does not need weakening.
- Source CinemachineVirtualCamera Follow/LookAt pointers both reference HoleParent
  transform888. Its serialized initial world Y is -.041, compared with reconstruction
  HolePosition Y=0. This small vertical framing difference is documented rather than
  converted into a constant before verifying the source's runtime follow target Y.
- Source Main Camera near/far clip values are .3/500; reconstruction uses .1/130.
  No claim of exact complete camera-pipeline or collection-physics equivalence is made.

Booster / feedback audit
- GameSettingsManager boot level0:412 and level1:1516 match parsed source
  work/reference5-audit/game-settings.json: Potion 8 seconds, activation level 3,
  increment 30%; Lightning 8 seconds, activation level 5, increment 30%; Finder
  12 seconds, activation level 9; Freeze 8 seconds, activation level 12.
  These existing recreation durations do not need replacement.
- GameIndicatorManager level2:2383 has maxIndicatorPerItems 5. Source Finder uses
  PositionIndicatorManager with target-on-screen and pointer-offscreen icons, not
  directional words. Sprite sharedassets2.assets:210 is named "terget"; :216 is
  "indicator-pointer_2". Source edge buffers are top580, bottom420, width115.
  Raw serialized evidence is saved separately in FinderSource7.json.
- OnJoyStickDirectionChanged (0x1977DF4) rotates the movement arrow using
  Quaternion.Slerp(current, Quaternion.LookRotation(-movementDirection, up), dt*40)
  if direction.sqrMagnitude>.01 and angular difference>1 degree. This is an
  interpolation coefficient, not a degrees-per-second value. Nonzero input controls
  visibility. Its calls resolve to LookRotation 0x522D2EC and Slerp 0x522CC84.
- That input handler first calls LTMx01.StartTimerOnGameStart (0x1974600), whose
  FirstGameTimerStarted guard starts the timer exactly once. The aligned ARM call
  scan over project code0x1700000-0x19A0000 found this only direct call at0x1977E3C.
  Reset the first-input timer flag per level; pressing Play alone should not spend
  countdown time. A deliberate test countdown setter can arm it explicitly.
- Countdown TimerCo (0x1975508) uses Time.realtimeSinceStartup differences, refreshing
  its markers during Pause and Freeze. This is distinct from motion's deltaTime;
  source elapsed countdown does not lose hitch time to maximumDeltaTime. The raw
  annotated method is preserved in CountdownNative7.txt. Its adaptive time factor
  TE is derived from GetEtForAtt / GetVetForVt settings and is not fully reconstructed;
  do not invent a rate from incomplete evidence.
- Source boosters are reusable after expiry if inventory allows. DeActiveSizeBoost
  (0x182F558) clears active state and calls BoosterTimeFinish (0x18B4058), which
  invokes BoosterButton.ResetBoosterButtonState (0x182B7E8). That restores Normal
  (or Locked based on level), not a permanent per-level Used state.
- Exact Finder sprites are extracted into Resources/ReferenceStyle: terget,
  indicator-pointer_2, indicator-circle_2. FinderSpriteSource7.json records source
  IDs and preserves the pointer's logical 256x256 rectangle despite trimmed pixels.
