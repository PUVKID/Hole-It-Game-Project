# 8차 수정 범위와 검증 기준

확인일: 2026-10-20. 출처: 윤석님의 이번 사용자 피드백과 7차 소스 조사.

- 큰 물체의 충돌 범위 일부만 수집 상자에 닿아도 다음 프레임에 전체를 제거하는 경로를 재현하고, 물체 전체가 실제 구멍 아래로 내려간 뒤에만 수집한다.
- 384개 물리 몸체가 모두 사용 중일 때, 원격 물체를 충돌 계산 없이 직접 아래로 이동시키는 대체 처리를 제거한다. 지지 물체의 실제 충돌체를 확보해 떠 있는 물체가 즉시 떨어지는 문제를 검증한다.
- 성장에 필요한 점수와 진행 상태를 화면에 표시하고 실제 성장 순간 알림을 복원한다. 원본에서 확인한 단계별 점수 기준은 근거 없이 변경하지 않는다.
- 작은 물체에 홀 방향의 힘이나 위치 보정이 없는지 검사한다. 물체를 누르거나 잡아당기지 않고 바닥 구멍, 충돌, 중력으로만 내려가도록 검증한다.
- 20레벨 관련 제보는 사용자가 잘못 말했다고 정정했으므로 이번 수정 대상에서 제외한다.
- 성공 기준: 일부만 걸친 큰 물체가 사라지지 않음, 작은 물체는 중력으로 낙하함, 홀 밖 물체는 홀을 따라 이동하지 않음, 물리 몸체 부족 시 수동 낙하 없음, 성장 수치와 표시가 같은 수집 프레임에 갱신됨.
- 7차와 원본 입력은 보존한다. 8차 APK와 소스 ZIP은 새 빌드 및 실제 검증 결과만 포함한다. 실패한 검사를 숨기거나 검증을 우회하지 않는다.
